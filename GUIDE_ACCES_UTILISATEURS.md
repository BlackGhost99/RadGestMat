# 📱 Guide d'Accès - RadGestMat

## Pour les Utilisateurs des Autres Départements

Ce guide explique comment accéder à l'application RadGestMat depuis votre PC ou smartphone.

---

## 🌐 Accès depuis un PC

### Étape 1 : Obtenir l'adresse de l'application

L'adresse de l'application est :
```
http://10.105.42.118:8000
```
*(IP fixe du serveur)*

### Étape 2 : Ouvrir votre navigateur

- **Chrome**, **Edge**, **Firefox** ou tout autre navigateur web

### Étape 3 : Saisir l'adresse

1. Dans la barre d'adresse, tapez : `http://10.105.42.118:8000`
2. Appuyez sur **Entrée**

### Étape 4 : Se connecter

1. La page de connexion s'affiche
2. Entrez vos **identifiants** (email et mot de passe)
3. Cliquez sur **"Se connecter"**

**Si vous n'avez pas de compte** : Contactez l'administrateur pour créer votre compte.

---

## 📱 Accès depuis un Smartphone

### ⚠️ IMPORTANT : Réseau WiFi

**Le smartphone doit être connecté au WiFi ADMIN** (pas au WiFi client HostHospitality).

- ✅ **WiFi Admin** : Réseau interne de l'hôtel (pour le personnel)
- ❌ **WiFi Client** : Réseau public pour les clients (ne fonctionne pas)

**Si vous ne savez pas quel réseau utiliser**, demandez à l'IT ou à votre responsable.

### Étape 1 : Se connecter au WiFi admin

1. Ouvrez les **Paramètres** de votre smartphone
2. Allez dans **WiFi**
3. Connectez-vous au réseau **admin** (pas le réseau client)

### Étape 2 : Ouvrir le navigateur

- **Chrome** (Android)
- **Safari** (iPhone)
- Ou tout autre navigateur

### Étape 3 : Saisir l'adresse

1. Dans la barre d'adresse, tapez : `http://10.105.42.118:8000`
2. Appuyez sur **Aller** ou **Entrée**

*(IP fixe du serveur)*

### Étape 4 : Se connecter

1. La page de connexion s'affiche
2. Entrez vos **identifiants** (email et mot de passe)
3. Appuyez sur **"Se connecter"**

### Étape 5 : Ajouter à l'écran d'accueil (Optionnel)

Pour accéder plus facilement à l'application :

#### Sur Android :
1. Ouvrez le menu (⋮) en haut à droite
2. Sélectionnez **"Ajouter à l'écran d'accueil"**
3. L'icône apparaîtra sur votre écran d'accueil

#### Sur iPhone (iOS) :
1. Appuyez sur le bouton **Partager** (carré avec flèche)
2. Sélectionnez **"Sur l'écran d'accueil"**
3. L'icône apparaîtra sur votre écran d'accueil

## ❓ Problèmes Fréquents

### "La page ne charge pas" ou "Connexion impossible"

**Vérifications à faire :**

1. **Vérifier l'adresse** : L'IP est-elle correcte ? (demander à l'administrateur)
2. **Vérifier le réseau** :
   - Sur PC : Êtes-vous sur le réseau admin ?
   - Sur smartphone : Êtes-vous sur le WiFi admin (pas le WiFi client) ?
3. **Vérifier que le serveur est démarré** : L'administrateur doit avoir lancé l'application

**Solution** : Contactez l'administrateur avec ces informations :
- Votre adresse IP (PC) ou nom du réseau WiFi (smartphone)
- Le message d'erreur exact

### "Nom d'utilisateur ou mot de passe incorrect"

1. Vérifiez que vous utilisez les bons identifiants
2. Vérifiez que le **Caps Lock** n'est pas activé
3. Si vous avez oublié votre mot de passe, contactez l'administrateur

### "L'application ne fonctionne plus"

**Causes possibles :**
- L'IP du serveur a changé (DHCP)
- Le serveur a été arrêté

**Solution** : Contactez l'administrateur pour obtenir la nouvelle adresse

### "Je ne peux pas me connecter depuis mon smartphone"

**Vérifications :**
1. Êtes-vous sur le **WiFi admin** ? (pas le WiFi client HostHospitality)
2. Le WiFi admin est-il actif et connecté ?
3. Pouvez-vous accéder à d'autres ressources du réseau admin ?

**Solution** : Si vous êtes sur le WiFi client, basculez sur le WiFi admin. Si le problème persiste, contactez l'IT.

**Les smartphones ne peuvent pas accéder à l'application** car le réseau admin est uniquement Ethernet (câblé). Utilisez un PC connecté en Ethernet au réseau admin.
